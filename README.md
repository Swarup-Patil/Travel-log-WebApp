# 🧭 Travel Log Application

![Image](https://github.com/user-attachments/assets/99447247-97ac-4673-ac8b-da1b35680f9d) <!-- Replace with actual screenshot -->

> A web-based travel log application that allows users to log their journeys, experience monuments through Augmented Reality, and sign in via Google authentication.

---

## 📌 Overview

The **Travel Log Application** offers travelers a unique platform to document their experiences and explore iconic locations through **Augmented Reality**. Users can sign in using **Google Authentication**, post travel blogs, and revisit the places they've been — virtually.

This project aims to simplify the travel journaling experience with immersive tech and intuitive design.

---

## 🛠️ Tech Stack

| Layer           | Technology           |
|----------------|----------------------|
| Frontend       | EJS, CSS, HTML       |
| Backend        | Node.js, Express.js  |
| Database       | MongoDB              |
| Authentication | Google Sign-In (OAuth) |
| AR Integration | AR.js (Marker-based) |

---

## 🎯 Features

- 🔐 **Google Sign-In**: Seamless login experience using OAuth.
- 📸 **Travel Blogging**: Log trips with location, photos, and stories.
- 🧱 **Augmented Reality (AR)**: Visualize monuments like India Gate using AR.js.
- 📂 **Personal Dashboard**: View and manage your past travel logs.

---

## 🔭 Future Scope

- 🌐 **Google Translate** for native-language accessibility
- 🧭 **Dynamic Google Routing** for optimized travel paths
- 🤖 **Chatbot Integration** for guided travel planning
